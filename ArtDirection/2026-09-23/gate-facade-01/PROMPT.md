# Gate facade V1

Built-in image_gen, reference: ../foundry-layout-01/foundry-v1.png (style/architecture only). Original output copied unchanged.

Use case: stylized-concept. Produce ONE game environment texture: an opaque full-bleed rectangular architectural FACADE, straight-on orthographic elevation, absolutely no perspective or isometric tilt. Reference image is STYLE AND ARCHITECTURE reference only, specifically its monumental upper-right boss gate. Recreate that gate's dark blue basalt, recessed steel double doors, narrow aged brass vertical trim, large circular split guild seal centered high across the door seam, two indigo hanging banners and flanking carved stone pilasters. The entire image rectangle must be occupied by physical wall/door material edge to edge, including all four corners. No sky, no outside background, no transparency, no ground plane, no stairs, no floor, no fog, no fire, no cast shadow outside the masonry. A level horizontal bottom threshold exactly flush with the image bottom; flat straight top lintel flush with top. Perfectly vertical jambs and symmetrical front elevation. Painterly high-quality readable mobile game architectural material, matching reference detailed stone and metal, restrained indigo/grey/brass palette, soft baked relief only. Image is a texture to be mapped onto an isometric vertical wall by Unity, so do NOT draw any perspective into the texture. Landscape aspect approximately 3:2. No text, no UI, no characters. Fill frame with gate facade, not a presentation sheet.
