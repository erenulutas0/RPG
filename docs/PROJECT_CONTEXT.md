# Project Context — Short Form for AI Agents

Build an original portrait mobile incremental auto-battler dungeon RPG.

Core fantasy:
weak hero → choices → synergy → absurd power → boss → permanent reward → repeat.

Current scope:
- Unity 6.x
- Android first
- single player
- local save
- placeholder art
- no backend
- no ads/IAP during mechanical prototype

MVP:
- 1 hero
- 3–5 weapons
- 4–6 enemies
- 1 boss
- 1 biome
- 10–20 run upgrades
- 1 meta progression layer

Priorities:
1. fun core loop,
2. first-session clarity,
3. replay desire,
4. technical stability,
5. art polish,
6. monetization.

Read full docs before architecture changes.
