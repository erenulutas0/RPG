## 6. Tools, traps and lessons

- `Tools/Run-UnityTests.ps1`, `Tools/UnityCompileCheck/`, `Tools/CombatChecks/`, `Tools/Verify-Project.ps1` — described in section 1. `TestResults/` and `Builds/` are ignored by Git; phone captures from earlier runs are there under `android-*.png` and `device-*/`.
- The Unity Editor lives at `E:/Unity/Editors/6000.0.65f1/Editor/Unity.exe` (not under Hub). Batch exit code **198** = the license lapsed; the owner restores it with the Unity CLI (`docs/23`, "License lapse and recovery").
- Test assemblies cannot call `EncodeToPNG` (no ImageConversion module): an Editor-side capture writes raw BGR and converts it outside Unity. A capture needs graphics (no `-nographics`); builders and tests do not.
- The Editor's culture is Turkish: format expected strings with the current culture in PlayMode tests.
- The `EventSystem` runs at execution order −1000 (set in its script's `.meta`), so `IsPointerOverGameObject` is valid in a script's first frame of a touch. Check `.meta` `executionOrder` values before reasoning about update order.
- PowerShell: `@(@('a','b'))` flattens to two strings (a "pairs" loop then replaced single characters and corrupted a file); `"$name:"` is a scope reference, write `"${name}:"`. Never pipe the Unity runner through `Tee-Object`.
- A run start (`Try again`) reloads the scene, which is where the 17.6 MB allocation and the 50–67 ms frame come from; the probe's window line reports the display as 30 Hz while frames arrive at 16.7 ms — do not trust that field.
- `FrameTimeProbe` output: `adb logcat -v time -s Unity:V | findstr /L "[Perf]"` (`/L`, or findstr reads the brackets as a character class); a window line every 5 s, a `wave:` line per spawn with `StartWave` ms, a `long frame` line past 35 ms. Numbers to beat are in `docs/23`, "Performance on the phone".
- Cosmetic issues already known: a never-triggered relic reads "Second Wind (0x)" on the result screen; both floors share one platform and backdrop although `19` gives Quicksilver Vaults cool silver tones; the death smoke is 55% size; a lone far-corner enemy hides behind the hero; the ring's far half passes behind enemies in front of the hero.
