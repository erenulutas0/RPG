# Market & Opportunity Research

## Reference game: Bones and Coins

As of 2026-09-12, Steam describes *Bones and Coins* as an incremental auto-battler dungeon crawler focused on:
- party building,
- hero synergies,
- weapons with distinct attack styles,
- loot,
- dungeon rooms,
- skill-tree progression.

Steam lists:
- 8 dungeon rooms,
- 16 weapons,
- 6 heroes,
- 9 enemies,
- 160+ upgrades.

The important signal is not the exact content count. The important signal is that a relatively compact content set can create a complete incremental RPG loop.

### What to learn from it
- mouse-only interaction strongly suggests the underlying interaction can translate to touch,
- readable auto-combat lowers control complexity,
- loot + upgrades + hero synergy gives multiple progression layers,
- content can be modular.

### What NOT to copy
- names,
- characters,
- UI,
- art style specifics,
- enemy design,
- progression structure,
- exact room/weapon/hero compositions,
- marketing copy.

Use the reference only as evidence that the loop is understandable.

## 2026 mobile benchmark reality

GameAnalytics' 2026 benchmark report (using 2025 mobile data) is a useful warning against outdated rules of thumb.

Reported global-ish performance tiers include:
- median D1 around 22%,
- top quartile D1 just above 30%,
- top 10% around 40% D1,
- median D7 just under 4%,
- top quartile D7 around 6–7%,
- top 10% D7 around 11–12%.

Europe in the report:
- D1 median: ~22.20%
- D1 top 10%: ~36.36%
- D7 median: ~4.06%
- D7 top 10%: ~11.31%
- D30 median: ~0.92%
- D30 top 10%: ~4.05%

The report also shows European median session length around 3.34 minutes and top-10% around 8.95 minutes.

### Practical conclusion

Do **not** use “D1 must be 35% or the game is dead” as an absolute rule.

Use stages:

**Prototype**
- qualitative replay desire,
- first-session clarity,
- build comprehension.

**Small soft launch**
- aim to beat median,
- investigate onboarding if D1 is weak,
- investigate progression if D7 collapses.

**Scale candidate**
- ideally trends toward top-quartile/top-decile retention for the specific traffic quality,
- monetization does not materially damage retention,
- acquisition creatives show repeatable appeal.

## Market thesis

### Why this concept fits mobile

1. **Low control burden**
Auto-battle is naturally touch-friendly.

2. **Short sessions**
Run progression can be chunked into 2–10 minute interactions.

3. **Habit loops**
Daily check-ins, offline rewards, unlock targets and collection fit mobile behavior.

4. **Creative-friendly marketing**
Transformation is easy to advertise:
“weak hero → absurd build → boss melts.”

5. **Content modularity**
New heroes/weapons/enemies can extend lifetime if architecture is data-driven.

### Why it is dangerous

1. **Mobile discovery is brutally competitive.**
A good game can still fail without marketable creatives.

2. **Idle/RPG players are trained by polished competitors.**
Clunky onboarding is punished immediately.

3. **Content treadmill risk.**
If fun depends only on adding more levels, solo development becomes unsustainable.

4. **Monetization can poison the loop.**
If progression is intentionally painful to sell relief, retention may collapse.

---

## Strategic positioning

Avoid competing head-on with giant collector RPGs.

Position closer to:
- “small, clever buildcraft RPG,”
- “idle game with real synergies,”
- “portrait dungeon run you can play in minutes.”

### Target emotional hooks
- power escalation,
- loot anticipation,
- build discovery,
- collection,
- mastery through synergy,
- “one more run.”

### Potential creative hooks for ads/social
- “This poison build looked useless until…”
- “Can one skeleton beat 100 enemies?”
- “I combined chain lightning + crit + burn.”
- split-screen bad build vs smart build,
- boss HP deletion,
- rare drop reaction,
- “choose one” upgrade moments.

---

## Opportunity decision

**Go** for prototype.

Reason:
- technical feasibility is high,
- content scope can be controlled,
- visual production can be AI-assisted,
- mobile interaction is naturally compatible.

But treat marketability as a first-class system:
- capture prototype footage early,
- make mock ads before full production,
- see whether strangers understand the appeal without explanation.
