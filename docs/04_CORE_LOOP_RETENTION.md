# Core Loop, Onboarding & Retention

## Retention thesis

Retention is earned by:
1. immediate comprehension,
2. frequent progress,
3. meaningful choices,
4. visible future goals.

Do not attempt to “fix retention” with notifications if the first session is weak.

## First 5 minutes

### 0–15 sec
- gameplay starts fast,
- one clear CTA,
- hero attacks,
- first enemy dies.

### 15–60 sec
- player receives first upgrade,
- choice has obvious consequence,
- short celebration.

### 1–3 min
- player sees at least one synergy,
- enemy variation appears,
- next unlock is previewed.

### 3–5 min
- elite/boss,
- meaningful reward,
- return loop visible.

## Tutorial philosophy

Use contextual micro-tutorials:
- highlight one button,
- explain one mechanic,
- remove tutorial immediately.

Avoid:
- 10-screen text tutorial,
- lore before gameplay,
- forced shop visit,
- forced ad,
- account creation before first play.

## Return hooks

Future, only after core loop works:
- offline rewards,
- daily objective,
- hero unlock progress,
- rotating modifier,
- daily free chest without paid-random mechanics,
- streak only if it does not punish missed days.

## Retention diagnostic tree

### Low tutorial completion
Likely:
- confusion,
- slow start,
- UI overload.

### Good tutorial completion, low first-run completion
Likely:
- pacing,
- difficulty spike,
- boring mid-run.

### Good D1, poor D7
Likely:
- shallow progression,
- insufficient build variety,
- goals become unclear,
- content repeats too quickly.

### Strong engagement, weak monetization
Do not immediately increase friction.
Test:
- better value communication,
- optional rewarded placements,
- cosmetic/value packs,
- remove-ads product.

## Benchmark interpretation

2026 GameAnalytics reporting indicates 2025 mobile medians around:
- D1 ~22%
- D7 <4%

Top quartile:
- D1 just above 30%
- D7 ~6–7%

Top decile:
- D1 ~40%
- D7 ~11–12%

These are context, not universal pass/fail rules.

## Suggested internal gates

### Tiny test (<100 players)
Focus on:
- tutorial completion,
- first upgrade time,
- first-run completion,
- session length,
- qualitative replay intent.

### Soft launch
Investigate if:
- D1 below ~20%,
- D7 below ~4%,
- first-session drop-off is concentrated before first upgrade.

Encouraging:
- D1 >30%,
- D7 >7%,
- meaningful repeated sessions.

Very strong:
- approaching top-decile territory with non-incentivized traffic.

Do not compare incentivized testers directly to paid UA.

## “One more run” mechanism

At end of run:
- show what was gained,
- show one near-term unlock,
- suggest one alternate build,
- restart in one tap.

Time from death/result to next combat should be short.
